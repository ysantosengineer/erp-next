# ERP Next

## Objetivo

Desenvolver um ERP moderno baseado em arquitetura profissional, capaz de atender pequenas e médias empresas.

O sistema servirá como principal projeto de portfólio Full Stack e será desenvolvido utilizando boas práticas de engenharia de software.

O projeto deverá demonstrar conhecimentos em:

- Arquitetura
- Backend
- Frontend
- Banco de Dados
- DevOps
- Testes
- CI/CD
- Segurança
- UX

---
