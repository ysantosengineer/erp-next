# Apresentação no GitHub

## About recomendado

- **Description:** `Multi-tenant ERP with transactional inventory, purchasing, sales, finance and analytics.`
- **Website:** `https://erp-next-web.vercel.app`
- **Topics:** `erp`, `nextjs`, `nestjs`, `typescript`, `postgresql`, `prisma`, `multi-tenant`, `rbac`, `inventory-management`, `github-actions`

Ative releases e deployments apenas quando houver conteúdo verificável. Fixe o repositório no perfil e mantenha o link público no campo Website.

## Social preview

Crie uma imagem 1200×630 com nome do produto, frase curta (“Purchasing, inventory, sales and finance in one traceable workflow”), captura real do dashboard e stack principal. Evite credenciais, selos inventados, estatísticas sem fonte ou texto pequeno. Configure-a em **Settings → General → Social preview**.

## Release sugerida

Após integrar esta etapa e validar produção, crie a tag `v1.0.0` e uma GitHub Release baseada em `CHANGELOG.md`. Não marque a versão antes de CI, links públicos e migrations estarem saudáveis.

## Checklist público

- README em inglês abre por padrão e aponta para português.
- Imagem principal carrega sem depender de host externo.
- CI está verde e o badge aponta para o workflow real.
- Live demo e health check respondem.
- About, topics, Website e social preview estão preenchidos.
- Issues, Projects e Wiki desnecessários podem ficar desativados.
- Branch `main` exige pull request e checks obrigatórios.
- Nenhum segredo, dado pessoal ou instrução interna aparece no histórico novo.
